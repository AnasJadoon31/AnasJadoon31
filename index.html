🛠️ GitHub Actions Setup Instructions:

  1. In your GitHub profile repository (e.g., username/username), create the folders .github/workflows/ if they do not exist.
  2. Create a new file named grs.yml in that directory.

  4. Commit the file to your main branch. The workflow will run daily to compile your static SVG cards. You can also trigger it manually from your repository's Actions tab!
